# 🌍 WanderAI - AI-Powered Travel Planner

**WanderAI** is a state-of-the-art travel itinerary generator built with **Next.js 15**. It leverages Artificial Intelligence to create personalized travel schedules based on user preferences, destination, and budget, making trip planning effortless and fun.

## 🌟 Key Features

* **🤖 AI Itinerary Generation:** Generates multi-day travel plans using advanced AI models via Vercel AI SDK.
* **🔒 Secure Authentication:** Implemented Google OAuth using **NextAuth.js**.
* **⚡ Server-Side Rendering (SSR):** Optimized performance and SEO using Next.js 15 App Router.
* **🎨 Premium UI/UX:** Built with **Shadcn UI** and **Tailwind CSS**.
* **💾 Trip Management:** Users can save and manage their trips in the dashboard.

## 🛠 Tech Stack

- **Frontend:** Next.js 15 (App Router), React 19, TypeScript
- **Styling:** Tailwind CSS, Shadcn UI
- **Auth:** NextAuth.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
